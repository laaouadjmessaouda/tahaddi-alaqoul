# 🎯 PFM Platform

> **أنت تملك الفكرة، والذكاء الاصطناعي هو منافسك.**
> من يستطيع ابتكار الحل الأفضل؟

منصة ويب تنظّم مسابقات قصيرة بين مشارك بشري ونموذج ذكاء اصطناعي.

---

## 🚀 التقنيات

- **React 18** + **Vite 5**
- **TailwindCSS 3**
- **React Router 6**
- **Zustand** (إدارة الحالة)
- **Axios** (الاتصال بـ API)
- **Framer Motion** (الحركات)
- **Lucide React** (الأيقونات)
